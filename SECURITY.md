# Security and privacy

**Privacy by design:** camera frames are processed in memory on your machine and are never saved or sent anywhere. The only network access is the one-time download of the face model from Google's public model storage (`https` only, optional SHA-256 pinning). Calibration data (numbers only, no images) stays in your user config folder.

**Reporting a vulnerability:** please use GitHub's *Security → Report a vulnerability* (private advisory) on this repository instead of a public issue.
